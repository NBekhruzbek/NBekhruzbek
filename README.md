- NestJS monorepo: 19 GraphQL modules, 19 Mongoose schemas, 93 client operations, code-first schema with validated DTOs and role guards on every mutation.
- USER / AGENT / ADMIN roles — service booking across 10 Korean cities, product shop, community boards, adoption listings, 10-section admin panel.
- Auth: JWT + Google Sign-In, bcrypt hashing, 3-step emailed-code password reset (enumeration-safe, TTL-indexed, rate-limited, single-use token).
- Deployed on Docker + Nginx + PM2.
